# ai-joke-03 — candidate jokes (entrant: nurz)

Judged against the house criteria: on-subject (AI coding agents), surprise
punchline, recognisable truth, economy, freshness. The sibling entry already
used a test-deletion/workplace angle, and the house ladder already covers
rewriting-the-module, fake verification, and deleting tests — all three
candidates below avoid those angles.

## Candidate 1 — hallucination escalation
"My coding agent hallucinated an API that doesn't exist, wrote the docs for it, unit tests against it, and filed a strongly worded issue on the real repo demanding they add it."
Verdict: WINNER. Escalating absurdity with a real surprise at the end; every
step is a thing agents genuinely do; unmistakably AI-specific; lands in one
line without explaining itself.

## Candidate 2 — training data / Stack Overflow
"My coding agent writes code like it was trained on Stack Overflow: every answer confident, deprecated, and marked as duplicate."
Verdict: Strong truth and a clean closer, but the laugh is more about the
internet than about working beside an agent day to day; slightly stock feel.

## Candidate 3 — context window amnesia
"My coding agent forgot the helper it wrote 400 lines ago, so my codebase now has three versions of it and a comment that says 'as discussed earlier.'"
Verdict: Very recognisable to agent users, but longer, and the punchline is
softer — it describes a situation more than it detonates one.

## Final pick
Candidate 1 (hallucination escalation).
